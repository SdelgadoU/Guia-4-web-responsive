## Abrir el proyecto

Extrae la carpeta completa y abre `index.html` en Microsoft Edge, Chrome o Firefox. No requiere instalación ni conexión a Internet. Conserva juntas las carpetas para que carguen los estilos, las imágenes y las interacciones.

También puedes usar un servidor estático desde este directorio, por ejemplo `python -m http.server 8000`, si ya tienes Python instalado, y abrir `http://localhost:8000`.

## Archivos

- `index.html`: estructura semántica y contenido.
- `css/styles.css`: estilos, Flexbox, Grid y Media Queries.
- `img/`: cuatro ilustraciones SVG originales del proyecto.
- `js/app.js`: menú, filtros y validación del formulario.
- `docs/Informe_APA7_Samuel_Delgado.pdf`: informe académico en APA 7, con portada, introducción, objetivos, desarrollo, pruebas, evidencias, conclusiones, referencias y apéndices.
- `docs/Contenido_editable.md`: texto editable del informe; la versión con paginación y formato APA es el PDF.
- `evidencias/computador.png`, `tableta.png`, `movil.png`: capturas completas de las tres resoluciones principales.
- `evidencias/reserva-movil.png`: resumen del formulario con datos de prueba.
- `evidencias/resultados-pruebas.json`: 36 comprobaciones aprobadas, versión de navegador y detalles.
- `evidencias/validacion-responsiva.webm`: video con siete capturas reales de pruebas y rótulos. Es un recorrido visual, sin voz ni grabación continua. Se puede abrir en Edge o Chrome.

## Funciones

El menú móvil se abre con el botón Menú y se cierra al elegir una sección o pulsar Escape. Los filtros muestran entradas, principales, postres o la carta completa. Las preguntas frecuentes son desplegables. El formulario comprueba campos obligatorios, correo, nombre, fecha futura o actual y cierre de los lunes.

**La reserva es una simulación:** no guarda ni envía datos, no verifica disponibilidad y no confirma una mesa real. El restaurante, el horario, los platos y los precios son ilustrativos. Usa datos de ejemplo.


Las referencias bibliográficas y la explicación completa de las decisiones de desarrollo se encuentran en el informe PDF.
